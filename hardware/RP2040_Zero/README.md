# Реконструкция Waveshare RP2040-Zero

Отдельный проект KiCad 10: схема и PCB модуля, локальные символы,
посадочные места и таблицы библиотек. `RP2040_Zero.pdf` — сохранённый
исходный материал; `FOOTPRINT_AUDIT.md` — подробности выбора посадочных мест.

Открывать `RP2040_Zero.kicad_pro`. Для стандартных компонентов нужны штатные
библиотеки KiCad. Проект не заменяет основную схему картриджа.

У L1 посадочное место намеренно не назначено: нумерация выводов
WS2812B-2020 расходится с исходной схемой; требуется сверка установленного LED.
P1/P2/P3 обозначают контактные площадки самой платы, а не отдельные разъёмы;
их геометрия должна быть задана при разводке.

Источник схемы: https://files.waveshare.com/upload/4/4c/RP2040_Zero.pdf

Готовность к производству
и результаты ERC/DRC этим проектом не подтверждаются.
