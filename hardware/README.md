# Аппаратная часть

## Проекты

- `breakout/` — разведённая отладочная плата с производственным архивом.
- `cartridge/` — основная схема картриджа и ранняя, пока не разведённая PCB.

Локальные библиотеки символов и посадочных мест хранятся рядом с проектом
картриджа. Благодаря этому проект открывается без неопубликованных глобальных
библиотек KiCad.

Перед выпуском аппаратной ревизии необходимо выполнить ERC/DRC и сверить LPF с
назначением выводов символа FPGA в схеме.
