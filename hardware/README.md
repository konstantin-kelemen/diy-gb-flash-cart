# Аппаратная часть

## Проекты

- `breakout/` — разведённая отладочная плата с производственным архивом.
- `cartridge/` — основная схема картриджа и PCB. Состояние разводки — в
  [STATUS.md](../docs/STATUS.md).

- `cartridge/power_mux.kicad_sch` — схема питания; `power_mux_board.kicad_pcb` и
  `power_mux_gerbers/` — отдельная плата и производственные файлы в работе.
- [RP2040_Zero/](RP2040_Zero/README.md) — реконструкция модуля RP2040-Zero.

## Открытие в KiCad

Открывайте `cartridge/cartridge.kicad_pro` или `breakout/breakout.kicad_pro`.
Локальные библиотеки и 3D-модели картриджа хранятся рядом с проектом;
`fp-lib-table` использует пути относительно `${KIPRJMOD}`.
Для стандартных компонентов также нужны штатные библиотеки KiCad.

В `cartridge/sym-lib-table` заданы конкретные файлы локальных символов.

Перед выпуском аппаратной ревизии необходимо выполнить ERC/DRC и сверить LPF с
назначением выводов символа FPGA в схеме.
