# Game Boy Flash Cartridge

DIY USB-programmable Game Boy flash cartridge based on:

- Lattice MachXO2-1200HC
- MX29LV320E 4 MB NOR Flash
- FM28V100 128 KB F-RAM
- RP2040
- SN74LVC8T245 level shifters

## Repository structure

- `hardware/`:   KiCad hardware designs
- `fpga/`:       MachXO2 HDL and Diamond project
- `firmware/`:   RP2040 firmware
- `docs/`:       Project documentation
- `references/`: Datasheets and third-party designs
- `releases/`:   Manufacturing releases
