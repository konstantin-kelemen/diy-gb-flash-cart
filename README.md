# FPGA-картридж с Flash-памятью для Game Boy

Экспериментальный USB-программируемый картридж для оригинального Game Boy.

Основные компоненты:

- FPGA Lattice MachXO2-1200HC;
- NOR Flash MX29LV320E объёмом 4 МБ для хранения ПЗУ;
- F-RAM FM28V100 объёмом 128 КБ для сохранений;
- RP2040-Zero для программирования по USB;
- преобразователи уровней SN74LVC8T245 между шиной Game Boy 5 В и логикой 3,3 В.

## Текущее состояние

Проверен базовый тракт
`Game Boy -> преобразователи уровней -> внутреннее ПЗУ FPGA`: на реальном
устройстве появляется логотип Nintendo. Работа с внешней Flash, прошивка
RP2040 и основная PCB картриджа находятся на стадии первичной проверки.

Перед продолжением работы см. [состояние проекта](docs/STATUS.md) и
[план работ](docs/ROADMAP.md).

## Источник истины

`hardware/cartridge/cartridge.kicad_sch` — нормативный источник электрических
соединений, назначений выводов, цепей питания и номиналов установленных
компонентов. При расхождении LPF, PCB, BOM или текстового документа со схемой
исправляется зависимый артефакт. PCB определяет только физическое размещение и
трассировку.

## Структура репозитория

```text
docs/          состояние, архитектура, план работ и план испытаний
hardware/      схемы, печатные платы и локальные библиотеки KiCad
fpga/          ограничения, тестовые конфигурации и проект Diamond
firmware/      будущая прошивка RP2040
host/          будущая программа записи и проверки для компьютера
references/    техническая документация и сторонние проекты
releases/      проверенные производственные файлы и сборки FPGA
```

Подробности по подсистемам находятся в файлах `README.md` соответствующих
каталогов.

## Безопасность

Стирание и запись Flash разрешены только в явно выбранном режиме `PROGRAMMER`.
После записи весь диапазон необходимо прочитать обратно по реальному тракту от
Flash до компьютера и побайтово сравнить с исходным файлом. До успешной
проверки подключать картридж к Game Boy для запуска записанного образа нельзя.
