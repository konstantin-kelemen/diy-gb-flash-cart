# GAME multi + PROGRAMMER, SPI v4

Дата сборки: 2026-09-10. FPGA: `LCMXO2-1200HC-4TG100C`, Diamond 3.14,
Lattice Synthesis Engine, стратегия Area, внутренний генератор 53.20 МГц.
Артефакт: [RomEmu_game_programmer.jed](RomEmu_game_programmer.jed).
Использовать парой с [RP2040 programmer-v4](../../rp2040/programmer-v4/MANIFEST.md).
Старый UF2 с SPI v3 для этой FPGA не подходит.

RP2040 выполняет обработку блоков до 1024 байт, хранение буферов, CRC блоков,
перебор адресов и пропуск записи FF. FPGA выполняет короткие SPI-команды,
аппаратные циклы Flash и переключение GAME/PROGRAMMER. Удержание режима на время
блока, подтверждённое освобождение и watchdog защищают передачу шины при смене питания.
В GAME определение MBC1M сравнивает все 48 байт ROM по адресам 0x104 и 0x40104;
константы логотипа нет. Совпадающие области из одних 00 или FF отклоняются.

## Проверки

- Синтез, MAP, PAR, TRACE, Bitgen: PASS, JEDEC экспортирован.
- MAP: **581/640 SLICE**, **1152/1280 LUT4**, 676 регистров, 0 EBR.
  Исходная неудачная сборка использовала 846 SLICE и 1679 LUT4.
- TRACE: **0 setup, 0 hold**, worst setup slack **0.998 нс** при 53.20 МГц.
  Покрытие соединений: 88.48%; асинхронные переходы от `gb_wr_n_c` не покрыты
  ограничением частоты внутреннего генератора.
- MAP/PAR завершены без ошибок размещения/маршрутизации. Сохранено предупреждение
  PAR: `gb_wr_n` на выводе 59 не является выделенным входом primary clock;
  используется общая трассировка с возможной дополнительной задержкой/перекосом.
  Распиновка сохранена. Отдельная аппаратная проверка внешней шины ещё нужна.
- Пять HDL-симуляций Questa из Diamond 3.14: PASS — cart_header, game_multi,
  programmer_block v3, game_programmer v3, SPI v4 с удержанием режима, ACK и watchdog.
- Реальный C-код RP2040 проверен с моделью SPI; см. манифест совместимого UF2.
- **На плате эта пара ещё не проверена.** Скорость чтения/записи не измерена;
  обмен короткими командами на каждый байт может быть медленнее прежнего блочного SPI.

Отчёты MAP, PAR, TRACE, полный журнал сборки и журнал регрессий лежат рядом.
Это функциональные RTL-симуляции, а не симуляция JEDEC с задержками.

## Исходники и воспроизведение

Базовый коммит: `122ff897a08f96814daeb0b47291b8ad3d7ae0bb`, с незакоммиченными изменениями.
Точный побайтовый снимок исходников FPGA, RP2040, тестов и документации находится
в `source/`; перечень его SHA-256 — `SOURCE_SHA256SUMS.txt`.
`SHA256SUMS.txt` покрывает весь комплект, включая снимок и манифест.
Зависимости SDK и компиляторы в снимок не включены; версии закреплены в манифесте RP2040.

Из корня снимка или соответствующего рабочего дерева:

```powershell
powershell -ExecutionPolicy Bypass -File fpga/targets/game_programmer/build.ps1
powershell -ExecutionPolicy Bypass -File fpga/tests/run.ps1
```

Путь Diamond по умолчанию: `C:/lscc/diamond/3.14`, меняется параметром `-DiamondRoot`.
CLI-сборка проверена полностью; GUI-сборка отдельно не запускалась.
Для GUI перезагрузить `fpga/diamond/RomEmu.ldf` и выбрать `game_programmer`
со стратегией `GameProgrammerArea`.
