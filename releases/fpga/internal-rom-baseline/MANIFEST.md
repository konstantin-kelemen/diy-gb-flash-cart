# Базовая конфигурация с внутренним ПЗУ

**Конфигурация:** `fpga/targets/internal_rom/top.v`

**Микросхема:** `LCMXO2-1200HC-4TG100C`

**Инструмент:** Lattice Diamond 3.14.0.75.2

**Исходный коммит:** `1aeeecbff7d8aaa29a92dd7763e7791884fe3699`

**Время сборки по отчёту Diamond:** 2026-09-02

После сборки исходник был перемещён, а повреждённые комментарии исправлены.
Логика HDL и назначения LPF при этой очистке намеренно не изменялись.

В документации зафиксирована проверка этой конфигурации на реальном Game Boy:
`логотип Nintendo -> чёрный экран`. Результат подтверждает чтение логотипа
загрузочным ПЗУ, но не полное выполнение тестовой программы.
