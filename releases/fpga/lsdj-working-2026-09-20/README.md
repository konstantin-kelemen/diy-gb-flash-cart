# LSDj working baseline — 2026-09-20

GAME multi + PROGRAMMER, MachXO2-1200HC-4TG100C, SPI v4.

Сохранён текущий JEDEC без пересборки. По результатам пользователя после
замены FM28V100 прежняя ошибка FRAM исчезла, LSDj 9.4.2 запускается.
Базовые диагностики FRAM проходят. Замена памяти — основное подтверждённое
изменение, устранившее проблему; дефект всей партии не установлен.

## Состав

- `RomEmu_game_programmer.jed` — FPGA-прошивка.
- Отчёты Diamond: MAP, PAR, TRACE, назначение выводов и экспорт.
- `fpga-source.zip` — снимок FPGA-исходников, ограничений, проекта,
  скриптов сборки, тестов и актуального `CONTEXT_FRAM.md`.
- `PROVENANCE.txt` — базовый Git commit и происхождение артефактов.
- `SHA256SUMS.txt` — SHA-256 всех файлов выпуска, кроме самого манифеста.

Снимок исходников включает локальные изменения проекта Diamond и не является
снимком исключительно чистого Git commit. Содержимое прошитой FPGA отдельно
не считывалось для сравнения с JEDEC. Игры, сохранения и дампы FRAM не включены.

## Проверки и ограничения

Сохранённый отчёт Diamond: 582/640 SLICE, 1156/1280 LUT4;
0 ошибок setup, 0 ошибок hold. Для ограничения 53,2 МГц расчётная
предельная частота — 62,727 МГц. Отчёт не подтверждает все внешние тайминги платы.

До аппаратного исправления пять наборов RTL-регрессий проходили на восстановленном
RTL. Аппаратный результат после замены FRAM зафиксирован со слов пользователя
в `CONTEXT_FRAM.md`; отдельный полный протокол повторных холодных запусков
и сохранности проекта LSDj после отключения питания пока отсутствует.

Для RP2040 используется существующий совместимый выпуск
[`programmer-v4`](../../rp2040/programmer-v4/); новая UF2 в этом выпуске не создавалась.

Для возврата к этому варианту используйте сохранённый JEDEC непосредственно:
повторная сборка исходников не гарантирует побайтово идентичный результат.
