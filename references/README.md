# Справочные материалы

- `datasheets/` содержит локальные копии технической документации на выбранные
  компоненты.
- `third-party/` содержит сторонние аппаратные проекты и модели корпусов.

Сторонние файлы не являются частью собственного проекта. Для каждого
импортированного материала следует сохранять исходную лицензию и сведения о
происхождении рядом с файлами.
