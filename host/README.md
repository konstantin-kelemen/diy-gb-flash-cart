# Программа для компьютера

Программа для компьютера пока не реализована.

Планируемые обязанности: чтение файла `.gb`, передача команд RP2040, вывод
состояния и ошибок, чтение Flash обратно по реальному тракту и побайтовая
проверка с выводом адреса первого несовпадения.

Для текущего теста достаточно USB CDC-терминала и
[команд прошивки RP2040](../firmware/rp2040/spi_bringup/README.md#запуск).
SPI-команда версии описана в [спецификации](../docs/SPI_BRINGUP.md);
протокол передачи команд памяти по USB ещё не определён.
