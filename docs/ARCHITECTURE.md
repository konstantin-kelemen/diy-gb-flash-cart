# Архитектура

## Общая схема

```text
Game Boy, шина 5 В
        |
        v
Преобразователи уровней SN74LVC8T245
        |
        v
FPGA MachXO2 <---- SPI ----> RP2040-Zero <---- USB ----> программа на компьютере
     |       |
     v       v
4 МБ Flash  128 КБ F-RAM
```

FPGA — единственное устройство, непосредственно управляющее параллельными
шинами Flash и F-RAM. RP2040 передаёт FPGA команды и данные по SPI и не имеет
отдельного подключения к полной параллельной шине памяти.

## Режимы работы

### GAME

Транзакции инициирует Game Boy. Flash доступна только для чтения, а её `WE#`
остаётся неактивным независимо от команд интерфейса программатора.

### PROGRAMMER

Сторона Game Boy не может инициировать транзакции памяти. Контроллер Flash в
FPGA получает право на чтение, стирание и запись только после явного выбора
этого режима.

Два владельца не должны одновременно управлять шиной памяти. Безопасные
неактивные состояния должны сохраняться также во время конфигурации FPGA и
переходных процессов любого источника питания.

## Ответственность подсистем

- MX29LV320E хранит ПЗУ Game Boy и работает в режиме x8.
- FM28V100 хранит сохранения без батареи.
- FPGA выполняет декодирование адреса, переключение банков, формирование
  временных параметров шины памяти и
  арбитраж.
- Прошивка RP2040 реализует передачу данных по USB и SPI-команд.
- Программа на компьютере полностью читает данные обратно, сравнивает их и
  сообщает адрес первого
  несовпадения.

## Питание

Game Boy предоставляет 5 В, а FPGA и память работают от 3,3 В. USB и Game Boy
не должны подавать питание друг в друга. Финальная схема стабилизатора,
изоляция источников и поведение при одновременном подключении пока не приняты.
