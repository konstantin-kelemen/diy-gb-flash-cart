# Архив документации

Файлы в этом каталоге сохранены только как исторические снимки. Они могут
содержать устаревшие номера выводов, номиналы и отметки комплектации.

`bom-2026-09-04.md` — прежний ручной план комплектации с таблицами соединений
и расчётами пассивных компонентов. Сохранён без актуализации для истории.

`misc-components-legacy.csv` — ранний ручной перечень компонентов, который
дублировал BOM и не был синхронизирован со схемой автоматически.
