# Прошивка RP2040

Реализация прошивки ещё не начата.

Первый этап — минимальный ведущий SPI и передача данных по USB, позволяющие
запросить у FPGA фиксированную версию протокола без обращения к Flash. Команды
чтения, стирания, записи, состояния и проверки памяти добавляются только после
стабилизации этого обмена.

Протокол обмена необходимо описать в `docs/` до появления зависимых от него
реализаций прошивки и программы для компьютера.
