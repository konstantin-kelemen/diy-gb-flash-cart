# Прошивка RP2040

Реализация прошивки ещё не начата.

2026-09-06 проведена проверка Flash на аппаратуре, сохранены
[артефакты теста](../releases/fpga/flash-bringup-pass/MANIFEST.md).
После исправления стартового сброса тест пройден: pin 82 — HIGH (`test_pass`),
pin 83 — LOW (`test_fail`), см. [журнал испытаний](../docs/TEST_PLAN.md).
Ближайшая задача прошивки — запустить тракт USB ↔ RP2040 ↔ SPI ↔ FPGA.

Первый этап — минимальный ведущий SPI и передача данных по USB, позволяющие
запросить у FPGA фиксированную версию протокола без обращения к Flash. Команды
чтения, стирания, записи, состояния и проверки памяти добавляются только после
стабилизации этого обмена.

Протокол обмена необходимо описать в `docs/` до появления зависимых от него
реализаций прошивки и программы для компьютера.

Порядок работ:

1. Зафиксировать выводы SPI, режим, частоту, формат кадров и коды ошибок.
2. Подготовить минимальную сборку RP2040 и USB-команду запроса версии FPGA.
3. Добиться повторяемого ответа версии без обращения к памяти.
4. Добавить чтение диапазона Flash и побайтово сравнить повторные чтения на ПК.
5. После проверки режима `PROGRAMMER` добавить стирание, запись, опрос
   состояния и полную проверку чтением обратно.

Ближайший критерий готовности: компьютер многократно получает верную версию
FPGA через USB/SPI. Общий порядок и критерии — в [ROADMAP.md](../docs/ROADMAP.md).
