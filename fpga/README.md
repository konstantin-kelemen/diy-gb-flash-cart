# Исходники FPGA

## Структура

```text
constraints/                 файлы LPF
diamond/                     проект Diamond и настройки стратегии
rtl/                         повторно используемые модули
targets/internal_rom/        проверенная конфигурация с внутренним ПЗУ
targets/flash_bringup/       аппаратный тест внешней Flash со стиранием
examples/fram_test.v         отложенный пример записи и чтения F-RAM
examples/hello_world.v       минимальный пример выхода FPGA
```

В каждой конфигурации есть собственный модуль `top`; конфигурации собираются
независимо. Повторно используемая логика находится в `rtl/`, а примеры, не
подключённые к проектам сборки, — в `examples/`.

Активный проект `RomEmu.ldf` собирает `targets/internal_rom/top.v` с
`constraints/internal_rom.lpf`. Diamond заново создаёт рабочий каталог
`diamond/v1_0/`, поэтому он исключён из Git.

## Проверка назначений выводов

Перед программированием реального устройства нужно выполнить процедуру сверки
LPF из `docs/TEST_PLAN.md`. Расхождения нельзя скрывать изменением текстовой
документации.

## Состояние конфигураций

- `internal_rom` — проверена на реальном Game Boy.
- `flash_bringup` — самостоятельный тест, не подключённый к проекту Diamond;
  подтверждённого результата пока нет.

Файлы из `examples/` не являются активными конфигурациями и не учитываются как
реализованные этапы проекта.

`flash_bringup` выполняет стирание и запись. Перед подключением микросхемы с
важными данными необходимо проверить адреса секторов и явно включить режим
программатора.
