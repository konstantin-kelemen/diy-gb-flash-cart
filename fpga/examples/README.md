# Примеры FPGA

Файлы в этом каталоге не входят в активные проекты сборки и не обозначают
завершённые этапы.

- `hello_world.v` — минимальный пример постоянного уровня на выходе FPGA.
- `fram_test.v` — ранний автономный тест записи и чтения F-RAM; работа с F-RAM
  отложена до завершения первичной проверки внешней Flash.

При возобновлении работы пример нужно перенести в отдельную конфигурацию,
добавить проверенные ограничения выводов и зафиксировать результат испытания.
